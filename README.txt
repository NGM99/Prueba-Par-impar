Para ejecutar la aplicacion solo se debe descargar el archivo "index"
hacer click derecho, elegir en el menu la opcion "Abrir con" y seleccionar 
el navegador donde se desea ejecutar.

La aplicacion realiza todas las tareas marcadas en el documento enviado a excepción
de la parte opcional marcada en el correo como Adicional.

Al realizar la practica solo investige algunas dudas en cuanto a si el 0 o numeros negativos 
pertenecian a Pares o Impares para la validacio y algunos problemas con la sintaxis 
de javascript asi como la creaccion del repositorio en github.
